# Visualization Toolkit

Choose the simplest tool that makes the model clear. Every diagram should have a purpose, readable labels and a nearby explanation.

## Architecture and flow diagrams

- [Mermaid Live Editor](https://mermaid.live/) — flowcharts, sequence diagrams, state diagrams, ER diagrams and timelines as text.
- [Excalidraw](https://excalidraw.com/) — fast sketching and teaching diagrams.
- [diagrams.net](https://app.diagrams.net/) — detailed architecture diagrams and exports.
- [Structurizr DSL](https://structurizr.com/dsl) — C4 architecture diagrams as code.
- [PlantUML](https://plantuml.com/) — UML and sequence diagrams as text.

## Data and API visualization

- [dbdiagram.io](https://dbdiagram.io/) — relational data models.
- [DBeaver](https://dbeaver.io/) — inspect database schemas and query plans.
- [Swagger Editor](https://editor.swagger.io/) — OpenAPI contract visualization.
- [Hoppscotch](https://hoppscotch.io/) — explore HTTP APIs.

## Performance and operations

- [Grafana](https://grafana.com/) — dashboards and telemetry visualization.
- [Prometheus](https://prometheus.io/) — metrics collection and querying.
- [OpenTelemetry](https://opentelemetry.io/docs/) — traces, metrics and logs instrumentation.
- [k6](https://grafana.com/docs/k6/latest/) — load testing and performance experiments.
- [Jaeger](https://www.jaegertracing.io/) — distributed trace visualization.

## Interactive learning and prototypes

- [Observable](https://observablehq.com/) — interactive explanations and data visualization.
- [Jupyter](https://jupyter.org/) — executable notebooks and experiments.
- [CodeSandbox](https://codesandbox.io/) — share small runnable web examples.
- [StackBlitz](https://stackblitz.com/) — browser-based runnable projects.

## Publishing diagrams

- Keep Mermaid, PlantUML or Structurizr source alongside exported images.
- Use SVG for scalable visuals where supported.
- Add meaningful alt text to raster or vector images.
- Cite third-party diagrams and do not rehost material without permission.
- Do not use screenshots of a diagram when its source can be maintained as code.
