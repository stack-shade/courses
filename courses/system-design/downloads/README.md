# Generated presentation downloads

PowerPoint files are generated from the Markdown slide sources in `docs/slides/` during the GitHub Pages workflow.

After the first successful deployment, use these links:

- [01 · Course kickoff (PPTX)](01-course-kickoff.pptx)
- [02 · Requirements and estimation (PPTX)](02-requirements-and-estimation.pptx)

If a download is not present yet, the Pages workflow has not completed successfully. The Markdown sources remain available in the repository and can be exported locally with Marp CLI.

Note: standard Marp PowerPoint export favors visual fidelity and renders slide pages as backgrounds. Edit the Markdown source for content changes; use the experimental editable export only when you accept its rendering limitations.
